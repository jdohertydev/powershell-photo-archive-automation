# Privacy and sanitisation

The original project handled private household data. This public repository is intentionally sanitised.

## Public-repo rules

No public file should contain:

- a family member's name;
- a real Windows username;
- a real Microsoft account identifier;
- a real personal document filename;
- a real photograph or video;
- an original source path;
- a raw original inventory, copy plan or verification log.

## Synthetic conventions used here

Examples use generic values such as:

- `C:\SyntheticSources\OneDrive`
- `C:\SyntheticSources\PC`
- `E:\SyntheticSources\SDCard`
- `D:\SyntheticArchive`
- `IMG_20240115_101500.jpg`
- `VID_20240203_183000.mp4`

These are invented examples and do not identify the original user or archive.

## Why raw CSVs are not published

The surviving project outputs are useful evidence, but they contain private filenames and filesystem paths. Publishing them would add little technical value while creating unnecessary privacy risk.

Instead, this repository provides synthetic examples that preserve the structure of the workflow without exposing personal data.
